# KEY ELEMENTS Protocol — Visual Grammar, Not Crops

## Purpose

KEY ELEMENTS answer:

> “What visual units make this image/reconstruction recognizable, distinctive, and structurally interesting?”

They are an explanatory layer, not a gallery of details.

## Required process

For each candidate:

1. Identify the underlying visual idea.
2. Isolate its geometry/relationship mentally — not by cropping pixels.
3. Redraw/recompose it independently using the reconstruction's palette and visual logic.
4. Remove context that is not needed to explain the unit.
5. Label it with a short structural name.

## Good element categories

- **Signature form:** hair silhouette, roof profile, hull shape, helmet pair.
- **Relationship:** supporting embrace, converging hands, interlocking bodies, bridge-to-crowd relation.
- **Structural junction:** pole + wire crossing, harness knot, layered eaves intersection.
- **Rhythm:** repeated roof tiers, window stack, crowd flow, ornamental scroll cadence.
- **Gesture/action:** reaching arm, upward thrust, collision axis.
- **Motif:** cloud scroll, lotus base, flag angle, wave geometry — only when source-derived.

## Forbidden shortcuts

- crop / screenshot / zoomed detail;
- direct mask/segmentation from Block 2;
- cloned local texture;
- generic SVG icon set;
- pictograms with artificially unified stroke width;
- replacing a relation with a single isolated object when the relation is the insight.

## Three tests

### A. Pixel-independence test

If the element visually looks like it was cut out of Block 2, redraw it. It must have its own composition.

### B. Grammar test

Can the element be described as a form, relation, rhythm, junction, gesture or motif? If the answer is only “this is a small part of the picture,” it fails.

### C. Teaching test

Does the element help a viewer notice something they might otherwise miss? If not, choose a more meaningful element.

## Visual treatment

KEY ELEMENTS do not need identical complexity. One may be a simple contour, another an ornate architectural module, another a relational two-body composition. Consistency comes from palette and editorial presentation, not forced icon uniformity.
