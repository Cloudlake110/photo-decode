# Layout Spec — Photo Decode

## Canvas

- Default ratio: **3:2 landscape**.
- Preferred master: **1536×1024** or equivalent.
- Background: warm ivory/off-white paper; subtle paper character is allowed but must not become a texture effect.

## Grid

Use one stable five-block editorial framework.

### Top row (~58–62% height)

- Left: **1. ORIGINAL SOURCE** (~48–50% width)
- Right: **2. REINTERPRETED VISUAL (FLAT)** (~50–52% width)

Top images should read as a deliberate before/after pair with aligned visual weight.

### Bottom row (~38–42% height)

- Left: **3. IMAGE ESSENCE** (~38–42% width)
- Center: **4. COLOR PALETTE** (~27–31% width)
- Right: **5. KEY ELEMENTS** (~27–31% width)

Do not create a sixth block.

## Section titles

Every block must visibly carry its numbered title:

1. ORIGINAL SOURCE
2. REINTERPRETED VISUAL (FLAT)
3. IMAGE ESSENCE
4. COLOR PALETTE
5. KEY ELEMENTS

Use small uppercase sans or monospaced typography. Titles are structural labels, not decorative headlines.

## Typography

- Main editorial title in IMAGE ESSENCE: restrained serif display.
- Subtitle/body: clean sans serif.
- HEX codes: small mono/sans, uppercase, directly beneath each swatch.
- Key-element labels: small sans/mono.

## Dividers and spacing

- Thin hairline rules only.
- Generous outer margin.
- Consistent baseline and gutters.
- Avoid boxes/cards unless the stable reference board explicitly requires them.

## Do not

- move COLOR PALETTE into the bottom-right position;
- replace KEY ELEMENTS with a second palette;
- add dates as decorative filler;
- add fake metadata, coordinates, location, brand, or year;
- turn the result into a presentation slide, scrapbook, UI dashboard, or generic moodboard.
