# Fixed Layout Spec

## Canvas

- 3:2 landscape; preferred 1536×1024 or equivalent.
- Warm ivory / off-white editorial paper.
- Thin hairline rules, generous margins.
- No UI-card/dashboard styling.

## Exactly five blocks

### Top row (~60%)

- Left ~48–50%: **1. ORIGINAL SOURCE**
- Right ~50–52%: **2. REINTERPRETED VISUAL (FLAT)**

### Bottom row (~40%)

- Left ~38–42%: **3. IMAGE ESSENCE**
- Center ~27–31%: **4. COLOR PALETTE**
- Right ~27–31%: **5. KEY ELEMENTS**

No sixth block. Do not append “SPATIAL NOTES” as a separate analysis zone. If structural notes are useful, incorporate them concisely into IMAGE ESSENCE.

## Typography

- Block labels: small uppercase sans/mono.
- Editorial title: restrained serif.
- Body: clean readable sans or serif.
- HEX: small uppercase mono/sans directly beneath swatch.

## Layout invariants

- COLOR PALETTE stays center-bottom.
- KEY ELEMENTS stays right-bottom.
- Every block visibly carries its exact numbered title.
- The board template remains stable while Block 2 remains source-adaptive.
