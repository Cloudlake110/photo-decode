# Prompt Compiler — Internal Generation Instruction

Use only after completing the Visual Structure Ledger.

## Fixed frame

Create a premium 3:2 editorial analysis board with exactly five blocks:

1. ORIGINAL SOURCE
2. REINTERPRETED VISUAL (FLAT)
3. IMAGE ESSENCE
4. COLOR PALETTE
5. KEY ELEMENTS

Warm ivory paper, disciplined grid, thin dividers, understated typography.

## Block 2 instruction

Reconstruct the source from its analyzed visual structure. Remove incidental background and photographic/painterly depth. Preserve the anchor, identity cues, important relations, source-derived rhythm and meaningful complexity. Use a source-adaptive flat visual language. Do not apply a named art style or universal texture. The result must be newly designed and standalone, not traced, filtered or simply vectorized.

## Block 4 instruction

After Block 2 exists, extract 5–8 useful colors from Block 2 only. Put uppercase HEX beneath every swatch.

## Block 5 instruction

Create 4–6 independently redrawn visual grammar units based on the analysis ledger and Block 2. Each unit should explain a signature form, relation, rhythm, structural junction, gesture/action or motif. Recompose each element independently. Do not crop, zoom, mask, segment or copy local pixels from Block 2. Do not convert the set into generic SVG/UI icons.

## Negative controls

No fixed engraving/woodcut/etching/comic/anime/vector preset. No crop-like key elements. No sixth block. No invented facts. No source-derived palette before reconstruction.
