# Transformation Pipeline — Complex → Flat

The right visual is a **new graphic object**, not a copy of the original.

## Stage 1 — Read

Identify:

- visual anchor;
- largest/most important masses;
- primary direction/gesture;
- repeated rhythm;
- strongest identity cues;
- important overlaps and asymmetry;
- context that can be deleted without losing recognition.

## Stage 2 — Select

Keep only the features needed to preserve identity or structural meaning.

A retained feature should pass at least one test:

- recognition test — removing it makes the subject hard to identify;
- structure test — it defines the composition or spatial relationship;
- rhythm test — it carries a distinctive repeated pattern;
- action test — it defines what is visibly happening;
- color-anchor test — it is necessary for the transformed visual system.

## Stage 3 — Remove

Delete:

- photographic/painterly background;
- incidental scenery;
- depth-of-field effects;
- realistic shadows and reflections;
- texture noise;
- small irrelevant props;
- tertiary objects that do not support the visual anchor;
- readable source text unless it is structurally essential and user wants it retained.

For landscapes, convert meaningful environmental layers into flat subject planes rather than keeping them as realistic scenery.

## Stage 4 — Compress

Reduce many details into fewer readable masses.

Examples:

- hundreds of leaves → one or two foliage masses + selected edge rhythm;
- building façade → stacked planes + aperture rhythm;
- crowd → 1 hero silhouette + 2 support masses + minimal tertiary marks;
- garment folds → one dominant contour + two or three color planes;
- product shelf → hero product blocks + shelf rhythm, not every package detail.

## Stage 5 — Flatten

Use:

- solid or near-solid color planes;
- clean silhouettes;
- simple internal cut lines;
- minimal tonal separation;
- restrained pattern fragments;
- limited palette;
- little or no realistic cast shadow.

Avoid:

- photorealistic relighting;
- pseudo-3D vector rendering;
- soft airbrushed gradients as a substitute for structure;
- generic poster motifs unrelated to the source;
- decorative circles/blobs/arcs merely to “balance” the layout.

## Stage 6 — Reorganize, but preserve truth

A new visual arrangement is allowed when it improves clarity and impact, but do not reverse essential spatial facts.

Preserve when identity-defining:

- left/right order;
- vertical/horizontal direction;
- main scale hierarchy;
- overlap/occlusion;
- gesture/action direction;
- group relationship;
- repetition density.

## Stage 7 — Derive downstream blocks

Only after the right visual exists:

- extract 5–8 palette colors from it;
- extract 4–6 key elements from it.

Never bypass the right visual and derive those blocks directly from the source.
