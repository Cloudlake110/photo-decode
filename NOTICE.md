## Upstream inspiration

Photo Decode / 解图 was developed through iterative visual testing and user feedback. Its general direction of turning a source image into an editorial visual reinterpretation was inspired in part by:

- ZzzLc0405/photo-abstract-editorial
  https://github.com/ZzzLc0405/photo-abstract-editorial

The upstream repository states that its Skill, prompts, workflow designs, documentation, and related original materials are available for personal, educational, research, and non-commercial use, while commercial use requires prior authorization.

Photo Decode does **not** include or redistribute the upstream repository's prompt files, example images, or documentation text. The workflow, five-block board contract, transformation pipeline, dependency rules, scene routing, quality gates, and supporting documentation in this repository were written for this project after iterative testing.

Because the project was developed with awareness of an upstream non-commercial work, users should independently verify all rights before commercial use or redistribution.

## Test images

Development used many user-supplied and reference images to test behavior across portraits, news, artworks, landscapes, groups, architecture, and product displays. Those source images and generated boards are intentionally **not included** in this repository unless their redistribution rights are separately confirmed.
