# Contributing to Photo Decode

Thanks for helping improve Photo Decode.

## Good contributions

We especially welcome improvements to:

- flat reinterpretation consistency;
- scene routing;
- group/news hierarchy selection;
- quality gates and eval cases;
- documentation and bilingual wording;
- rights-safe example cases.

## Do not silently change the contract

The five-block framework and its dependency chain are v1.0 stability guarantees. A proposal that changes them should explain the user benefit and include before/after eval evidence.

## Example submissions

Only submit source images and generated boards that you have the right to redistribute publicly. If rights are unclear, provide an eval description without the image.

## License

Contributions are accepted under the repository's current non-commercial source-available license unless a future release explicitly changes the licensing model.
